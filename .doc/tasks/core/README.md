# Core Backlog

Date: 2026-05-31

This section contains backlog items that belong in the minimal `OfficeDocuments` core.

Core features should:

- directly support straightforward document generation or document data access
- improve efficient work with `.xlsx` and `.docx`
- keep the public API small, predictable, and lightweight
- avoid unnecessary dependency footprint or disproportionate architecture cost
